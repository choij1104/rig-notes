# Rig Notes — EMT 26F study app

Personal study app for Texas 26 F EMT I (National EMS Academy San Antonio).

- `index.html` — flashcards, practice quiz, rapid review, due dates
- `audio/` — MP3s for listening while driving (flashcards, quiz, rapid review)

Built 2026-11-13 from the MyLab BRADY Ch 8 learning outcomes, the Canvas Module 1 Study Guide and the Ch 7 Review.
Textbook body (Prehospital Emergency Care, 12th ed.) not yet cross-checked.
