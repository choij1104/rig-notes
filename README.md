# Rig Notes — EMT 26F study app

Personal study app for Texas 26 F EMT I (National EMS Academy San Antonio).

- `index.html` — Chapters (theory per chapter + that chapter's cards and quiz, read-aloud), due dates, flashcards, practice quiz, listen mode, rapid review
- `audio/` — MP3s for listening while driving

Chapters covered: Module 1 (Ch 7 A&P, Ch 8 Pathophysiology), Module 2 (Ch 1–6). Textbook: Prehospital Emergency Care, 12th ed.
Every card and quiz item carries a chapter tag (item order unchanged, so saved progress is kept).
